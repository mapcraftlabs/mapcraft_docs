## View Simulations

**[Admin] [Editor] [Viewer]**

To view project simulations, use the *Simulations Dropdown Menu* to select a simulation.

![simulations dropdown](simulations_dropdown.jpg)

On the main project panel, use the *Maps Panel* to select and view project inputs and outputs on the map. Use the "Map Appearance" settings to select basemap layers that provide simulation context. The Aerial view can be a helpful basemap for validating simulation results.

![map appearance](map_appearance.jpg)

The *Analytics Tab* on the main project panel displays the simulation's summary statistics. Zoom in to the Analysis Layer to see the summary statistics for a given simulation for a parcel analysis layer, for example. Zoom out to see the Parent Layer and compare the output statistics by summary geography.

### Compare Simulations

To compare simulations in the app, click the "Compare Scenarios" button after selecting a simulation. Use the dropdowns in the split page to select two simulations to compare.

![compare scenarios](compare_scenarios.jpg)

To inspect the inputs behind these simulation outcomes, return to the main dropdown menu and select an input layer to activate its comparison, then use the dropdowns in the split page to select the two input layer scenarios to compare.
